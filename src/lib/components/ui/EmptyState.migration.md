# EmptyState Component - Migration Guide

This guide helps migrate from domain-specific empty states to the centralized UI EmptyState component.

## Why Migrate?

### Benefits of the New Component

✅ **Consistency**: Same look and feel across the entire application
✅ **Flexibility**: More variants and customization options
✅ **Accessibility**: Built-in ARIA attributes and keyboard support
✅ **Maintainability**: Single source of truth for empty states
✅ **Features**: Illustrations, multiple sizes, better error handling

## Migration Checklist

### Step 1: Update Imports

**Before:**
```svelte
import EmptyState from '$lib/components/events/EmptyState.svelte';
```

**After:**
```svelte
import EmptyState from '$lib/components/ui/EmptyState.svelte';
// Or use barrel export:
import { EmptyState } from '$lib/components/ui';
```

### Step 2: Update Component Usage

The new component has a more flexible API. Here's how to migrate each variant:

## Events EmptyState Migration

### Variant: First Time

**Before:**
```svelte
<EmptyState variant="first-time" />
```

**After:**
```svelte
<EmptyState
	variant="no-content"
	title="Create Your First Event"
	description="Get started by creating an unconference event. Set up voting, discussion groups, and interactive activities in minutes."
	illustration="create"
	actionLabel="Create New Event"
	onAction={handleCreateEvent}
/>
```

### Variant: No Results

**Before:**
```svelte
<EmptyState variant="no-results" filterText={searchQuery} />
```

**After:**
```svelte
<EmptyState
	variant="no-results"
	title={searchQuery ? `No events match "${searchQuery}"` : "No events found"}
	description="Try adjusting your filters or create a new event"
	illustration="search"
	actionLabel="Clear Filters"
	onAction={clearFilters}
/>
```

### Variant: Loading

**Before:**
```svelte
<EmptyState variant="loading" />
```

**After:**
```svelte
<!-- Use LoadingScreen instead for loading states -->
<LoadingScreen />

<!-- Or if you want a loading empty state: -->
<EmptyState
	variant="no-content"
	title="Loading Events..."
	description="Please wait while we fetch your events"
	icon="⏳"
/>
```

## Complete Before/After Example

### Events Page - Before

```svelte
<script>
	import EmptyState from '$lib/components/events/EmptyState.svelte';

	let events = $state([]);
	let searchQuery = $state('');
	let isLoading = $state(false);

	const filteredEvents = $derived(/* filtering logic */);
</script>

{#if isLoading}
	<EmptyState variant="loading" />
{:else if filteredEvents.length === 0}
	{#if events.length === 0}
		<EmptyState variant="first-time" />
	{:else}
		<EmptyState variant="no-results" filterText={searchQuery} />
	{/if}
{:else}
	<!-- Events grid -->
{/if}
```

### Events Page - After

```svelte
<script>
	import { EmptyState, LoadingScreen } from '$lib/components/ui';
	import { goto } from '$app/navigation';

	let events = $state([]);
	let searchQuery = $state('');
	let isLoading = $state(false);

	const filteredEvents = $derived(/* filtering logic */);

	function handleCreateEvent() {
		goto('/events/create');
	}

	function clearFilters() {
		searchQuery = '';
	}
</script>

{#if isLoading}
	<LoadingScreen />
{:else if filteredEvents.length === 0}
	{#if events.length === 0}
		<EmptyState
			variant="no-content"
			title="Create Your First Event"
			description="Get started by creating an unconference event. Set up voting, discussion groups, and interactive activities."
			illustration="create"
			actionLabel="Create New Event"
			onAction={handleCreateEvent}
			size="lg"
		/>
	{:else}
		<EmptyState
			variant="no-results"
			title={searchQuery ? `No events match "${searchQuery}"` : "No events found"}
			description="Try adjusting your filters or search terms"
			illustration="search"
			actionLabel="Clear Filters"
			onAction={clearFilters}
		/>
	{/if}
{:else}
	<!-- Events grid -->
{/if}
```

## Additional Use Cases to Implement

### Topics List

```svelte
{#if topics.length === 0}
	<EmptyState
		variant="no-content"
		title="No topics submitted yet"
		description="Share your ideas and help shape the agenda"
		icon="💡"
		actionLabel="Suggest Topic"
		onAction={openTopicModal}
	/>
{/if}
```

### Discussion Groups

```svelte
{#if !groups || groups.length === 0}
	<EmptyState
		variant="no-content"
		title="No discussion groups assigned"
		description="Room assignments will appear once they're generated by the organizer"
		illustration="empty"
		size="lg"
	/>
{/if}
```

### Search Results

```svelte
{#if searchResults.length === 0 && searchQuery}
	<EmptyState
		variant="no-results"
		title="No results for '{searchQuery}'"
		description="Try different keywords or browse all content"
		illustration="search"
		actionLabel="Clear Search"
		onAction={() => searchQuery = ''}
	/>
{/if}
```

### Admin Dashboard

```svelte
{#if !userIsAdmin}
	<EmptyState
		variant="permission"
		title="Admin access required"
		description="You need administrator privileges to access this page"
		illustration="lock"
		actionLabel="Contact Admin"
		onAction={() => goto('/contact')}
		size="lg"
	/>
{/if}
```

### API Error

```svelte
{#if error}
	<EmptyState
		variant="error"
		title="Failed to load data"
		description={error.message || "An unexpected error occurred"}
		illustration="error"
		actionLabel="Try Again"
		onAction={retry}
	/>
{/if}
```

### Coming Soon Feature

```svelte
{#if !featureEnabled}
	<EmptyState
		variant="coming-soon"
		title="Advanced analytics coming soon"
		description="We're building powerful insights for your events. Stay tuned!"
		illustration="rocket"
		actionLabel="Learn More"
		onAction={() => goto('/roadmap')}
	/>
{/if}
```

## Cleanup Steps

Once migration is complete:

1. **Remove old component**:
   ```bash
   rm src/lib/components/events/EmptyState.svelte
   ```

2. **Update imports** in all files that used the old component

3. **Test all empty states**:
   - Empty lists
   - No search results
   - Error states
   - Permission walls
   - Loading states (use LoadingScreen instead)

4. **Check accessibility**:
   - Screen reader announcements
   - Keyboard navigation
   - Focus management

## Common Patterns

### Pattern 1: Conditional with Loading

```svelte
{#if loading}
	<LoadingScreen />
{:else if error}
	<EmptyState variant="error" title="Error" description={error} actionLabel="Retry" onAction={retry} />
{:else if items.length === 0}
	<EmptyState variant="no-content" title="No items" description="Create your first item" actionLabel="Create" onAction={create} />
{:else}
	<!-- Content -->
{/if}
```

### Pattern 2: Search with Empty State

```svelte
{#if results.length === 0}
	{#if query}
		<EmptyState variant="no-results" title="No results for '{query}'" actionLabel="Clear" onAction={clear} />
	{:else}
		<EmptyState variant="no-content" title="Start searching" description="Enter a query above" />
	{/if}
{/if}
```

### Pattern 3: Permission Wall

```svelte
{#if !hasPermission}
	<EmptyState variant="permission" title="Access denied" description="You don't have permission" actionLabel="Request Access" onAction={request} />
{:else}
	<!-- Protected content -->
{/if}
```

## TypeScript Support

The new component has full TypeScript support:

```typescript
interface EmptyStateProps {
	variant?: 'no-results' | 'no-content' | 'error' | 'permission' | 'coming-soon';
	title: string;
	description?: string;
	icon?: string;
	actionLabel?: string;
	onAction?: () => void;
	illustration?: 'search' | 'create' | 'error' | 'lock' | 'rocket' | 'empty';
	size?: 'sm' | 'md' | 'lg';
	class?: string;
}
```
